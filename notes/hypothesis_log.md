# Hypothesis Log

Pravidlo: **zdůvodnění se píše PŘED spuštěním testu.** Pokud píšeš zdůvodnění až po výsledku, log je k ničemu (data snooping).

---

## Template (zkopíruj pro každou novou hypotézu)

### [YYYY-MM-DD] Název hypotézy

- **Hypotéza:** (jedna věta — co testuješ)
- **Zdůvodnění (napsáno PŘED testem):** proč by to teoreticky mělo fungovat
- **Data:** tickery / období / zdroj
- **Metoda:** jak přesně počítáno (korelace, regrese, porovnání skupin...)
- **Očekávaný výsledek (napsáno PŘED testem):** co bys čekal, kdyby hypotéza platila
- **Skutečný výsledek:** konkrétní číslo/čísla
- **Verdikt:** potvrzeno / zamítnuto / nejednoznačné
- **S kým:** Claude / Gemini / sám
- **Poznámky:**
